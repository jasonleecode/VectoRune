Noto Sans Regular SDF glyph ranges bundled for offline Latin/pinyin map labels.

Source: https://demotiles.maplibre.org/font/Noto%20Sans%20Regular/{range}.pbf
Ranges: 0–255, 256–511, 8192–8447.
Font license: SIL Open Font License 1.1, in OFL.txt.
License source: https://github.com/google/fonts/blob/main/ofl/notosans/OFL.txt

These ranges cover this IMG's Windows-1252 labels; other scripts need additional
glyph ranges. The font files are extracted to the temporary map directory so the
native renderer can read them without a network request.
